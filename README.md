# Cloud Engineering Journey 🚀

Welcome to my hands-on learning journey toward becoming a **Cloud Engineer**.

I am a BCA student building practical skills in Linux, computer networking, AWS cloud services, cloud security, and automation. This repository documents my daily learning, practical exercises, troubleshooting experience, and projects.

## 🎯 Goals

- Build a strong foundation in Linux and networking.
- Learn AWS cloud services and cloud architecture.
- Understand IAM, security, monitoring, and cost management.
- Practise Bash scripting and infrastructure automation.
- Build practical projects and prepare for Cloud Engineer interviews.

## 📚 Learning Roadmap

### 1. Linux Administration
- Basic Linux commands
- File and directory management
- Users, groups, and permissions
- Processes and services
- Logs and troubleshooting
- SSH and server administration

### 2. Computer Networking
- IP addresses and subnetting
- DNS and DHCP
- TCP and UDP
- Common ports and protocols
- HTTP and HTTPS
- Routing, firewalls, and network troubleshooting

### 3. AWS Cloud Computing
- AWS global infrastructure
- IAM and access management
- EC2 and EBS
- S3 storage
- VPC, subnets, and route tables
- CloudWatch and monitoring
- Billing and cost optimization

### 4. Automation and DevOps
- Git and GitHub
- Bash scripting
- Python for automation
- Terraform fundamentals
- Docker and CI/CD

## 🛠️ Hands-on Practice

I will document each exercise with:

1. **Objective:** What I want to learn.
2. **Commands:** The commands or configuration used.
3. **Expected output:** What successful execution looks like.
4. **Explanation:** Why the commands work.
5. **Troubleshooting:** Errors encountered and how I resolved them.
6. **Key takeaways:** What I learned from the exercise.
